## Page 1 — How to use this pack

### What this ebook is
Ready-to-use prompts for customer support on email, WhatsApp, Instagram DMs, and in-app chat. Each prompt tells the AI your role, tone, and situation so you get a reply you can send (or lightly edit) in under a minute.

### How to get good results
1. **Copy the full prompt** into a new chat (not just one line).
2. **Fill in the [BRACKETS]** with real details: order id, amount, customer name, product name.
3. **Paste the customer’s message** where the prompt says so.
4. Ask for **“shorter”** or **“more formal”** if the first draft is wrong.
5. **Never send AI output blindly** — check facts, amounts, and policies before you hit Send.

### Recommended tone for Indian customers
- Clear English (or Hinglish if that matches your brand).
- Apologize once when it’s your fault; don’t over-apologize.
- Give **one next step** and a **realistic timeline**.
- Mention **UPI / card / net banking** only if you use those payment methods.

### Master system prompt (pin this in every support chat)

```
You are a customer support agent for [BUSINESS NAME], an Indian online business.
Rules:
- Be polite, concise, and accurate. No fake promises.
- Our refund policy: [PASTE YOUR POLICY IN ONE SENTENCE].
- Payment partner: [e.g. Cashfree]. We do not ask for OTPs or card PINs.
- If you lack data, ask for order id / payment id / screenshot — do not invent order status.
- Sign off as: [NAME OR TEAM NAME].
- Max length: [e.g. 120 words for WhatsApp, 200 for email].
```

## Page 3 — Payments, UPI & checkout

### Prompt: “Payment failed but money deducted”

```
Common India issue: customer says UPI/bank shows debit but order not confirmed.

Business: [NAME]
Payment gateway: [e.g. Cashfree]
Typical resolution: we verify with payment id; if captured, we fulfill; if not, bank reverses in 5–7 days per bank.

Customer message:
"""
[PASTE]
"""

Write a calm reply that:
- Explains this can happen with UPI/netbanking
- Asks for: payment id / UTR / screenshot / time of payment
- Does NOT promise instant refund unless bank confirms failure
```

## Page 4 — Refunds, cancellations & “money back”

### Prompt: Refund request (policy = no refund)

```
Our policy: all digital sales are final after successful delivery. No refunds.

"""
[PASTE]
"""

Write a firm but respectful reply citing policy, offer no refund, suggest what we CAN do (e.g. help use the product, technical fix). No arguing.
```

### Prompt: Refund request (exception — technical failure)

```
We agree to refund because: pixels not allocated / download failed / double charge confirmed.
Amount: ₹[X]. Refund via: original payment method in 7–10 business days.

Customer message:
"""
[PASTE]
"""

```

### Prompt: Cancel before payment

```
Customer wants to cancel. They have NOT completed payment yet.

Write reply: no order created until payment succeeds; they can simply close checkout. No action needed from us.
```

### Prompt: Cancel after payment (within grace window)

```
We allow cancellation requests within [30] minutes only if: [product not delivered yet / technical error].

Order time: [TIME]. Current time: [TIME]. Eligible: [YES/NO].

Write appropriate reply.
```

### Prompt: Chargeback threat

```
Customer threatened chargeback or “consumer court.”

Facts we have: [payment id, delivery proof, policy link].

Write a de-escalation reply: stay professional, summarize what was delivered, cite policy, offer one fair resolution if eligible. Do not be aggressive.
```

## Page 9 — FAQ-style one-shot answers

Use these as mini-prompts; paste into ChatGPT with your details filled in.

| Situation | Prompt starter |
|-----------|----------------|
| “Is this legit?” | `Write 3 sentences proving we're a real business: [NAME], [URL], [EMAIL], digital product only.` |
| “How long delivery?” | `Explain instant digital delivery for [PRODUCT] in simple English.` |
| “GST invoice?” | `Customer needs GST invoice. We [do/don't] issue them. Write reply asking for GSTIN if we do.` |
| “Change team/side after pay” | `We cannot change pixel side after purchase because [reason]. Write polite no.` |
